Gráficos

Um gráfico de barras desenhado em <canvas> via JavaScript e um emblema em SVG estilizado com CSS.

Autoavaliação de habilidades

O gráfico é desenhado inteiramente por script — nenhuma imagem é usada. Os botões redesenham as barras e alternam a paleta de cores usada no preenchimento.

Emblema pessoal

Emblema simples com as minhas iniciais, desenhado em SVG e estilizado inteiramente pelo CSS externo.
